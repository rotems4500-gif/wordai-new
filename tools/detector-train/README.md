# Detector training loop — אימון הגלאי המקומי

כלי offline לחיזוק הגלאי `src/services/styleAuthenticityService.js` מקורפוס מתויג.
הלולאה: מוסיפים דגימות → מאפיינים → מגלים מרקרים → מרחיבים לקסיקון → מאמתים.

## קבצים
- `extractor.mjs` — מראה verbatim של ליבת הפיצ'רים מהשירות (רץ ב-Node טהור). **לסנכרן ידנית** עם השירות אם הליבה משתנה.
- `train.mjs` — מנתח: ממוצעי סיגנל לכל מחלקה, weights+סף מכויל, דיוק, וגילוי n-grams שכיחים ב-AI/נדירים באנושי.
- `samples/ai.txt` — דגימות AI (בלוקים מופרדים בשורת `===`).
- `samples/human.txt` — דגימות אנושיות (אותו פורמט).

## הרצה
```bash
node tools/detector-train/train.mjs          # ניתוח
node tools/detector-train/train.mjs --emit   # + כותב calibration.json
```

## איך מוסיפים דאטה אמיתי (הלולאה)
1. שולחים את הפרומטים שב-`PROMPTS.md` ל-Gemini ול-ChatGPT.
2. מדביקים כל פלט כבלוק חדש ב-`samples/ai.txt` (מפרידים ב-`===`).
3. מדביקים טקסטים אנושיים אמיתיים (שלך/של אחרים) ל-`samples/human.txt`.
4. מריצים `train.mjs`, מסתכלים על "מרקרים מועמדים חדשים".
5. מרקרים עם lift גבוה + human=0 → מוסיפים ל-`FORMAL_CONNECTORS`/`CLICHE_PHRASES`
   ב**שני** הקבצים (השירות + extractor.mjs).
6. חוזרים עד שאין מרקרים חדשים משמעותיים.

## הערות כיול
- ה-baseline (weights ברירת מחדל, סף 60) מפריד מצוין על קורפוס עמוס.
  ה-weights ה"מאומנים" נטו ל-overfit (false-positive בודד) — לכן **לא** צרבנו אותם;
  הערך מגיע מהרחבת הלקסיקון.
- `lowRichness` כמעט לא נורה בעברית (TTR גבוה בשתי המחלגות) — סיגנל חלש מטבעו.
- מרקרי מניין (`ראשית,`/`שנית,`) נשמרים עם פסיק כדי לא לתפוס "בראשית"/"השלישית".
