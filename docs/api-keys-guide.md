# מדריך למתחילים: מה זה API Key ואיך מקבלים אותו

אם זו הפעם הראשונה שאתה רואה את המושג API Key, הכל טוב.
אפשר לחשוב על זה כמו סיסמה אישית שמאפשרת לאפליקציה לדבר עם שירות ה-AI עבורך.

## אילו מפתחות כדאי להגדיר

- Gemini API Key (מומלץ להתחלה): כתיבה, ניסוח, שכתוב ופעולות הצ'אט הראשיות. יש רובד חינמי נדיב.
- OpenAI API Key (אופציונלי): מודלים של GPT כאלטרנטיבה או השלמה.
- Perplexity API Key (אופציונלי): חיפוש מקורות וסיוע מחקרי.

מספיק מפתח אחד (Gemini) כדי להתחיל לעבוד. אפשר להוסיף ספקים נוספים בכל שלב דרך הגדרות ← מנועי AI.

## איך מוציאים Gemini API Key

1. פתח את הקישור: https://aistudio.google.com/app/apikey
2. התחבר לחשבון Google שלך.
3. לחץ על יצירת מפתח חדש (Create API key).
4. העתק את המפתח ושמור אותו.
5. באפליקציה, פתח הגדרות ← מנועי AI והדבק בשדה Gemini API Key.

## איך מוציאים OpenAI API Key

1. פתח את הקישור: https://platform.openai.com/api-keys
2. התחבר לחשבון OpenAI שלך.
3. צור מפתח חדש (Create new secret key).
4. העתק את המפתח מיד (הוא מוצג פעם אחת בלבד) ושמור אותו.
5. באפליקציה, הדבק בשדה OpenAI API Key.

## איך מוציאים Perplexity API Key

1. פתח את הקישור: https://www.perplexity.ai/settings/api
2. התחבר לחשבון Perplexity שלך.
3. צור מפתח חדש.
4. העתק את המפתח ושמור אותו.
5. באפליקציה, הדבק בשדה Perplexity API Key.

## טיפים חשובים למתחילים

- לא משתפים API Key עם אף אחד.
- לא מעלים API Keys ל-GitHub.
- אם יש חשש שדלף מפתח, מוחקים אותו ומנפיקים חדש.
- המפתחות נשמרים מוצפנים במחשב שלך (בגרסת הדסקטופ — הצפנת Windows DPAPI).

## מה עושים אם לא עובד

- ודא שהמפתח הודבק במלואו בלי רווח בתחילה/בסוף.
- ודא שלחצת על "שמור מפתחות".
- סגור ופתח מחדש את האפליקציה.
- מדריך מפורט יותר זמין גם בתוך האפליקציה: עזרה ← מדריך חיבור API.
